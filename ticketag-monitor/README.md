# Ticketag Monitor — laboratorio separato

Questo ramo contiene un piccolo laboratorio separato dal sito principale per verificare una singola chiamata pubblica di TicketOne/Ticketag.

**Non effettua login, acquisto o polling automatico.**

Il test viene eseguito manualmente tramite GitHub Actions e serve a capire se la risposta HTTP/JSON dell'endpoint può essere usata per rilevare disponibilità.

## Prossimo passo

Eseguire manualmente la workflow `Ticketag API test` dalla scheda Actions di GitHub. Il risultato viene mostrato nei log della workflow.
