⛽ FUEL DATA API

Distributori e prezzi carburante geolocalizzati, pronti per siti, app e piattaforme di terzi.

RICHIEDI ACCESSO API →

🔑 Autenticazione

Ogni cliente riceve una API Key personale. La chiave va inviata nell'header x-api-key. Ogni piano ha un limite mensile configurabile.

x-api-key: LA_TUA_API_KEY

📍 Endpoint principale

Cerca distributori vicino a coordinate GPS, con raggio e numero massimo di risultati personalizzabili.

GET /functions/v1/fuel-api/v1/nearby

🚀 Esempio richiesta

GET https://pyiheodneyvtcotuonpt.supabase.co/functions/v1/fuel-api/v1/nearby?lat=44.4056&lon=8.9463&radius=10&limit=20 x-api-key: LA_TUA_API_KEY

Parametri: lat, lon, radius (0,5–100 km), limit (1–100). L'API restituisce dati e metadati della ricerca.
